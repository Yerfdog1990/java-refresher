# Working With Arrays 

## 1. Overview

An array is a fundamental data structure in Java that stores a **fixed-size, sequential** collection of elements of the **same data type**. This lesson covers how to create arrays, print them, and access, update, and iterate over their elements.

- Start module: [arrays-start](https://github.com/Baeldung/learn-java-collections/tree/module1/arrays-start)
- Fully implemented reference: [arrays-end](https://github.com/Baeldung/learn-java-collections/tree/module1/arrays-end)

---

## 2. Array Structure

Think of an array as a series of **labeled boxes**, where each box holds a single value of a specific type. The labels — called **indices** — start at `0` and go up to the number of elements minus one.

Example: an array of 8 numbers `5, 10, 15, 20, 25, 30, 35, 40` has 8 elements labeled `0` to `7`:

```
Index:   0    1    2    3    4    5    6    7
       +----+----+----+----+----+----+----+----+
Value: | 5  | 10 | 15 | 20 | 25 | 30 | 35 | 40 |
       +----+----+----+----+----+----+----+----+
```

Key facts:

- Array indices in Java are **zero-based** — the first element is at index `0`, the second at `1`, and so on.
- The **length** (or **size**) is the total number of elements.
- Every element must be of the **same data type** (e.g. `int`, `String`, `boolean`).

---

## 3. Creating an Array in Java

There are two ways to create an array.

### Option 1 — Declare with a specified size

The array is automatically filled with **default values** (`0` for numeric types, `false` for booleans, `null` for objects).

```java
dataType[] arrayName = new dataType[size];
```

```java
@Test
void whenCreated_thenLengthIsFixed() {
    int[] scores = new int[5];

    assertEquals(5, scores.length);
}
```

Here, `scores` can hold five integer values. **Once created, an array's size cannot be changed.**

### Option 2 — Initialize with values at declaration

More concise when the elements are already known.

```java
dataType[] arrayName = {value1, value2, value3, ...};
```

```java
@Test
void whenInitializedWithValues_thenSizeMatchesNumberOfEntries() {
    int[] numbers = { 10, 20, 30, 40, 50 };

    assertEquals(5, numbers.length);
}
```

Java automatically infers the size from the number of elements provided (five here).

---

## 4. Accessing Array Elements

Access an element with the array name followed by the index in square brackets:

```java
arrayName[index]
```

For the `numbers` array: `numbers[0] -> 10`, `numbers[1] -> 20`, and so on (index starts at `0`).

```java
@Test
void whenAccessingFirstNumber_thenCorrectValueReturned() {
    int[] numbers = { 10, 20, 30, 40, 50 };

    int firstNumber = numbers[0];

    System.out.println("The first number is: " + firstNumber);
    assertEquals(10, firstNumber);
}
```

Console output:

```
The first number is: 10
```

> **Safety point:** Accessing an index less than `0` or greater than/equal to the array's length throws an `ArrayIndexOutOfBoundsException`. For a length-5 array, `numbers[5]`, `numbers[10]`, and `numbers[-1]` all fail. Always keep indices within valid bounds (`0` to `length - 1`).

---

## 5. Updating Array Elements

Assign a value to an element the same way you access it.

```java
scores[0] = 5;
scores[1] = 10;
scores[2] = 15;
scores[3] = 20;
scores[4] = 25;
```

Elements can also be overwritten after assignment:

```java
@Test
void whenScoreIsAdjusted_thenRevisedValueIsStored() {
    int[] scores = { 5, 10, 15, 20, 25 };

    System.out.println("The second score is initially: " + scores[1]);
    assertEquals(10, scores[1]);

    scores[1] = 25;
    System.out.println("The second score is now: " + scores[1]);
    assertEquals(25, scores[1]);
}
```

Output:

```
The second score is initially: 10
The second score is now: 25
```

Here we overwrite the value at index `1` (originally `10`) with `25`.

## 6. Iterating Over Arrays

To operate on every element, use a loop.

### Standard `for` loop

A good choice when you need the **index** of each element.

```java
@Test
void whenIteratingUsingForLoop_thenAllNumbersAreVisited() {
    int[] numbers = { 10, 20, 30, 40, 50 };

    for (int i = 0; i < numbers.length; i++) {
        System.out.println("Element at index " + i + ": " + numbers[i]);
    }
}
```

`numbers.length` gives the total count. The loop variable `i` runs from `0` up to `length - 1`.

Output:

```
Element at index 0: 10
Element at index 1: 20
Element at index 2: 30
Element at index 3: 40
Element at index 4: 50
```

### Enhanced `for` loop (for-each)

Simpler when you only need the **values** and not the indices — shorter and easier to read.

```java
@Test
void whenUsingEnhancedForLoop_thenAllNumbersAreVisited() {
    int[] numbers = { 10, 20, 30, 40, 50 };
    for (int number : numbers) {
        System.out.print(number + " ");
    }
}
```

Each iteration automatically assigns the next element to `number` — no manual index management.

Output:

```
10 20 30 40 50
```

Using `print()` instead of `println()` keeps all numbers on one line, separated by spaces.

## 7. Quick Reference

| Task | Syntax / Example |
|---|---|
| Declare with size | `int[] scores = new int[5];` |
| Initialize with values | `int[] numbers = {10, 20, 30, 40, 50};` |
| Get length | `numbers.length` |
| Access element | `numbers[0]` |
| Update element | `scores[1] = 25;` |
| Index `for` loop | `for (int i = 0; i < numbers.length; i++)` |
| For-each loop | `for (int number : numbers)` |

**Default values:** `0` (numeric), `false` (boolean), `null` (objects).
**Common exception:** `ArrayIndexOutOfBoundsException` — index outside `0 .. length-1`.

## 8. Conclusion

Arrays give us a simple way to work with a fixed-size, ordered collection of same-type values. We saw that arrays use **zero-based indexing** and that their **size is fixed** once created. We covered creating arrays (by size or with values), accessing and updating elements, and iterating with both the standard `for` loop and the enhanced for-each loop. A key safety habit is keeping indices within valid bounds to avoid runtime errors.

These tools cover the most common array tasks, from simple lookups to full traversals.
